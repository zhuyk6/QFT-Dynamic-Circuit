# Bench Scripts

This directory contains standalone benchmark scripts for dynamic QFT and Shor
benchmark experiments. Run them from the project root with `uv run python` so
the local package and pinned environment are used.

Qiskit simulation scripts write schema-version-2 counter `ExperimentDataset`
JSON files containing full logical counts. All downstream bench inputs and plot
inputs use the same counter format; probability conversion stays in memory.
Metrics and plots are derived downstream. The examples below use small
parameters for quick smoke runs; increase `--num-shots`, `--m-mc`, or the
qubit count for production data.

## `bench_fidelity.py`

Simulates the target circuits needed by dynamic-QFT process fidelity for one or
more batch sizes. Exact mode enumerates every target `k`; sampled mode selects a
reproducible target subset. Both modes save one complete logical counter per
selected target and do not calculate fidelity during acquisition.

Example:

```bash
uv run python benches/bench_fidelity.py results/fidelity.json \
  --num-qubits 12 \
  --batch-sizes 1 \
  --batch-sizes 2 \
  --batch-sizes 3 \
  --mode sample \
  --num-shots 10000 \
  --num-samples 20 \
  --seed 7
```

## `bench_perfect_enc.py`

Simulates the baseline, perfect delayed-encoding, and modified-readout variants
on a circular-state input. Each configuration is saved as a logical-count group;
TVD is calculated by the plotting consumer.

Example:

```bash
uv run python benches/bench_perfect_enc.py results/perfect-enc.json \
  --num-qubits 12 \
  --batch-sizes 1 \
  --batch-sizes 2 \
  --batch-sizes 3 \
  --delay-time 1e-7 \
  --num-shots 100000
```

## `find_best_batch_size.py`

Provides several dataset generators for comparing batch sizes:

- `run-circular`: circular-state counts for all combinations of gate, readout,
  and thermal-relaxation noise.
- `run-ghz`: GHZ-state counts for all combinations of the same noise toggles.
- `run-time`: estimated runtime for each batch size.
- `run-counts-vs-num-qubits`: one circular-state dataset per qubit width. A
  directory is required because `num_qubits` is a dataset-level invariant.

Examples:

```bash
uv run python benches/find_best_batch_size.py run-time \
  --num-qubits 12 \
  --batch-sizes 1 \
  --batch-sizes 2 \
  --batch-sizes 3
```

```bash
uv run python benches/find_best_batch_size.py run-circular results/circular.json \
  --num-qubits 12 \
  --batch-sizes 1 \
  --batch-sizes 2 \
  --batch-sizes 3 \
  --num-shots 100000
```

## `bench_shor_simulation.py`

Runs Qiskit simulations for a Shor benchmark instance and saves one logical
count run per phase label `s` in an `ExperimentDataset`. These datasets can
later be passed to `bench_shor_strict.py` as empirical sampler inputs.

Example:

```bash
uv run python benches/bench_shor_simulation.py input 15 2 4 8 2 \
  results/shor-dataset.json \
  --num-shots 4096
```

Using an instance JSON file:

```bash
uv run python benches/bench_shor_simulation.py file \
  results/instance.json \
  2 \
  results/shor-dataset.json \
  --num-shots 4096
```

## `bench_shor_strict.py`

Computes strict Shor benchmark curves for the finite-Q ideal sampler, uniform
baseline, arithmetic-ideal closed-form estimate, and optional experimental
logical datasets generated by `bench_shor_simulation.py`.

Example:

```bash
uv run python benches/bench_shor_strict.py input 15 2 4 8 \
  results/shor-strict.json \
  --k-list 1 \
  --k-list 2 \
  --k-list 4 \
  --k-list 8 \
  --m-mc 5000 \
  --seed 7 \
  --experiment-datasets results/shor-dataset.json
```

Using an instance JSON file:

```bash
uv run python benches/bench_shor_strict.py file \
  results/instance.json \
  results/shor-strict.json \
  --k-list 1 \
  --k-list 2 \
  --k-list 4 \
  --k-list 8
```

## `bench_shor_depolarized.py`

Runs a strict Shor robustness sweep under the application-level depolarized
finite-Q model
`P_lambda(y | s) = (1 - lambda) P_ideal(y | s) + lambda / Q`. Each lambda value
can be evaluated in a separate worker process.

Example:

```bash
uv run python benches/bench_shor_depolarized.py input 15 2 4 8 \
  results/shor-depolarized.json \
  --k-list 1 \
  --k-list 2 \
  --k-list 4 \
  --num-lambdas 11 \
  --m-mc 5000 \
  --seed 7 \
  --sample-method bitwise \
  --max-workers 0
```

Using an instance JSON file:

```bash
uv run python benches/bench_shor_depolarized.py file \
  results/instance.json \
  results/shor-depolarized.json \
  --k-list 1 \
  --k-list 2 \
  --k-list 4
```
