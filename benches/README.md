# Bench Scripts

This directory contains standalone benchmark scripts for dynamic QFT and Shor
benchmark experiments. Run them from the project root with `uv run python` so
the local package and pinned environment are used.

Most scripts write JSON or pickle outputs. The examples below use small
parameters for quick smoke runs; increase `--num-shots`, `--m-mc`, or the
qubit count for production data.

## `bench_fidelity.py`

Benchmarks dynamic-QFT process fidelity for one or more batch sizes. It supports
an exact mode that enumerates every basis state and a sampled mode that uses a
Monte Carlo estimator.

Example:

```bash
uv run python benches/bench_fidelity.py results/fidelity.json \
  --num-qubits 12 \
  --batch-sizes 1 \
  --batch-sizes 2 \
  --batch-sizes 3 \
  --mode sample \
  --num-shots 10000 \
  --num-samples 20 \
  --seed 7
```

## `bench_perfect_enc.py`

Compares measurement-encoding variants on a circular-state input by measuring
TVD between the ideal and noisy output distributions. It reports the baseline
circuit, delayed measurement encoding with perfect readout, and delayed
measurement encoding with modified readout probabilities.

Example:

```bash
uv run python benches/bench_perfect_enc.py results/perfect-enc.json \
  --num-qubits 12 \
  --batch-sizes 1 \
  --batch-sizes 2 \
  --batch-sizes 3 \
  --delay-time 1e-7 \
  --num-shots 100000
```

## `find_best_batch_size.py`

Provides several utilities for comparing batch sizes:

- `run-circular`: circular-state TVD for all combinations of gate, readout, and
  thermal-relaxation noise.
- `run-ghz`: GHZ-state TVD for all combinations of the same noise toggles.
- `run-time`: estimated runtime for each batch size.
- `run-tvd-vs-num-qubits`: circular-state TVD as the total number of qubits
  changes.

Examples:

```bash
uv run python benches/find_best_batch_size.py run-time \
  --num-qubits 12 \
  --batch-sizes 1 \
  --batch-sizes 2 \
  --batch-sizes 3
```

```bash
uv run python benches/find_best_batch_size.py run-circular results/circular.pkl \
  --num-qubits 12 \
  --batch-sizes 1 \
  --batch-sizes 2 \
  --batch-sizes 3 \
  --num-shots 100000
```

## `bench_shor_simulation.py`

Runs Qiskit simulations for a Shor benchmark instance and saves per-phase-label
histograms. These histogram files can later be passed to `bench_shor_strict.py`
as experimental sampler inputs.

The manual-input subcommand is currently named `intput` in the script.

Example:

```bash
uv run python benches/bench_shor_simulation.py intput 15 2 4 8 2 \
  results/shor-histograms.json \
  --num-shots 4096
```

Using an instance JSON file:

```bash
uv run python benches/bench_shor_simulation.py file \
  results/instance.json \
  2 \
  results/shor-histograms.json \
  --num-shots 4096
```

## `bench_shor_strict.py`

Computes strict Shor benchmark curves for the finite-Q ideal sampler, uniform
baseline, arithmetic-ideal closed-form estimate, and optional experimental
histograms generated by `bench_shor_simulation.py`.

Example:

```bash
uv run python benches/bench_shor_strict.py input 15 2 4 8 \
  results/shor-strict.json \
  --k-list 1 \
  --k-list 2 \
  --k-list 4 \
  --k-list 8 \
  --m-mc 5000 \
  --seed 7 \
  --experiments-histograms results/shor-histograms.json
```

Using an instance JSON file:

```bash
uv run python benches/bench_shor_strict.py file \
  results/instance.json \
  results/shor-strict.json \
  --k-list 1 \
  --k-list 2 \
  --k-list 4 \
  --k-list 8
```

## `bench_shor_depolarized.py`

Runs a strict Shor robustness sweep under the application-level depolarized
finite-Q model
`P_lambda(y | s) = (1 - lambda) P_ideal(y | s) + lambda / Q`. Each lambda value
can be evaluated in a separate worker process.

Example:

```bash
uv run python benches/bench_shor_depolarized.py input 15 2 4 8 \
  results/shor-depolarized.json \
  --k-list 1 \
  --k-list 2 \
  --k-list 4 \
  --num-lambdas 11 \
  --m-mc 5000 \
  --seed 7 \
  --sample-method bitwise \
  --max-workers 0
```

Using an instance JSON file:

```bash
uv run python benches/bench_shor_depolarized.py file \
  results/instance.json \
  results/shor-depolarized.json \
  --k-list 1 \
  --k-list 2 \
  --k-list 4
```
