# Plot Scripts

This directory contains Matplotlib scripts for turning benchmark outputs into
figures. Run them from the project root with `uv run python`. Detailed CLI
options are intentionally left to Typer; use `--help` on any script or
subcommand when you need the exact argument list.

The shared files `matplotlib_config.py` and `plot_config.toml` define the common
plot style and are not standalone plotting entrypoints.

## `plot_qft_experiment.py`

Plots normalized physical process-fidelity data. Repeated source files with the
same `k` metadata are pooled. Four subcommands provide complementary views:

- `overview`: overlaid `P(output=k)` curves and exact process fidelity;
- `targets`: one target-probability panel per experiment group;
- `stages`: mean MSB-prefix success at configured completed-output sizes;
- `summary`: one exact process-fidelity bar per experiment group.

```bash
uv run python plots/plot_qft_experiment.py targets \
  results/qft-logical-probabilities.json \
  results/qft-targets.pdf

uv run python plots/plot_qft_experiment.py stages \
  results/qft-logical-probabilities.json \
  results/qft-stages.pdf

uv run python plots/plot_qft_experiment.py summary \
  results/qft-logical-probabilities.json \
  results/qft-summary.pdf
```

The probability input JSON is produced by
`devtools/normalize_experiment_data.py`. Repeated runs are pooled using their
preserved shot counts. Completed-output sizes are explicit group attributes in
the dataset manifest; they are not inferred from batch size. The same plotting
commands can consume either normalized or readout-mitigated probability
datasets.

## `plot_fidelity.py`

Plots dynamic-QFT process fidelity versus the number of qubits. Each dynamic-QFT
batch size is drawn as a curve with mean and standard deviation aggregated over
matching result files. It can also overlay baseline curves from a CSV file.

Data source:

- Main input: JSON files generated by `benches/bench_fidelity.py`.
- The script scans a results directory for files named like `qft*.json` and
  reads their `fidelity_by_batch_size` field.
- Optional input: an external baseline CSV, not produced by a bench script in
  this repository.

## `plot_perfect_enc.py`

Plots a grouped bar chart comparing measurement-encoding methods for each batch
size. The bars show TVD for `base`, `enc perfect`, and `enc modify`.

Data source:

- JSON output generated by `benches/bench_perfect_enc.py`.

## `plot_find_best_batch_size.py`

Contains two plotting subcommands for batch-size search experiments:

- `plot-sampler-batch`: plots TVD versus batch size, with one subplot for each
  noise configuration.
- `plot-batch-num-qubits`: plots TVD versus the number of qubits, with one curve
  for each batch size.

Data source:

- `plot-sampler-batch` reads pickle output from
  `benches/find_best_batch_size.py run-circular` or
  `benches/find_best_batch_size.py run-ghz`.
- `plot-batch-num-qubits` reads pickle output from
  `benches/find_best_batch_size.py run-tvd-vs-num-qubits`.
- `benches/find_best_batch_size.py run-time` prints runtime estimates directly
  and does not produce an input file for this plotting script.

## `plot_shor_strict.py`

Plots Shor strict benchmark results. The left panel shows strict order-recovery
success probability versus sample count `K` for the ideal, uniform, arithmetic,
and optional experimental curves. The right panel shows a stacked breakdown of
success, wrong, and reject probabilities for one selected experiment curve.

Data source:

- JSON output generated by `benches/bench_shor_strict.py`.
- If the strict benchmark JSON includes experimental curves, those curves come
  from histogram files originally generated by `benches/bench_shor_simulation.py`
  and passed into `bench_shor_strict.py`.

## `plot_shor_depolarized.py`

Plots Shor strict robustness under the depolarized finite-Q model. The main
figure shows strict success probability versus noise mixture `lambda`, with one
curve per `K`. With the theory overlay enabled, sampled points are compared
against approximate theory curves.

Data source:

- Main input: JSON output generated by `benches/bench_shor_depolarized.py`.
- Optional theory overlay input: an instance JSON with `order_factors`, generated
  by `devtools/generate_shor_instance.py`. This extra file is used to compute the
  approximate theory curves and is not a bench output.

## `plot_shor_depolarized_theory.py`

Plots approximate theoretical Shor strict-success curves under the depolarized
model. This is a theory-only plot: it draws success probability versus `lambda`
for selected `K` values.

Data source:

- Instance JSON with `order_factors`, generated by
  `devtools/generate_shor_instance.py`.
- No `benches/` output is required for this script.

## `plot_shor_benchmark_on_depolarized.py`

Projects strict benchmark results onto depolarized success curves. The figure
draws depolarized curves versus `lambda`, then marks the selected benchmark
curve (`ideal`, `uniform`, `exp0`, and so on) as star points at the inferred
effective depolarized noise level. It also prints the average inferred
`lambda`.

Data source:

- Strict benchmark JSON generated by `benches/bench_shor_strict.py`.
- Instance JSON with `order_factors`, generated by
  `devtools/generate_shor_instance.py`.
- In `theory` mode, depolarized curves are computed from the approximate theory
  formula, so no depolarized bench output is needed.
- In `sample` mode, the depolarized curves come from JSON output generated by
  `benches/bench_shor_depolarized.py`.
